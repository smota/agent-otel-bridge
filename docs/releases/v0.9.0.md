# Release v0.9.0 — Native Linux Runtime & Multi-Home Wiring

Release v0.9.0 brings native Linux runtime support, lean static ELF hook packaging, transactional multi-home hook configuration for Linux and WSL, and resilient Unix domain socket daemon recovery under persistent leases.

## Native Linux hook runtime

- Lean static ELF packaging for `agent-hook` under 300 KB built via `scripts/build-linux-hook.sh` and verified with `scripts/check-linux-hook.py`.
- Passive hook responses on Linux: returns empty JSON objects (`{}`) across all harnesses and events, removing approval and environment-injection output while preserving inherited `TRACEPARENT` context propagation and original JSON over native IPC.
- Omission of blocking Linux AGY (Antigravity CLI) pre-tool telemetry hook to guarantee fail-open backstop and prevent turn stalling.

## Multi-home and WSL transactional hook wiring

- Transactional hook wiring supporting explicit per-home planning and discovery across multi-home Linux and WSL environments via `--all-homes` and per-home targeting.
- Atomic staging, backup creation, file ownership preservation (UID/GID), rollback recovery on fault, and isolated lock/permission handling.
- Coexistence with existing third-party hooks and unmanaged client configurations.

## Unix domain socket recovery and user service

- Stale Unix domain socket listener recovery in `agent-otel-ipc` serialized under a nonblocking private persistent file lease.
- Reclaims only verified owned sockets whose bounded connect probe returns connection refused, while refusing live listeners or ambiguous socket paths.
- Native Linux user systemd unit template at `deploy/systemd/agent-otel-bridge.service` configured with persistent lease tracking, graceful SIGINT draining, and automatic restart.

## CI and release publishing

- CI and release workflows publish native Linux (`x86_64-unknown-linux-gnu`) tarballs, standalone static `agent-hook` binaries, and SHA-256 checksums alongside Windows releases.
- Fixed SemConv dependency fetching with supported manifest options and restored all-target Linux compilation and test isolation.
- Isolated test fixtures for reporting collector readiness probes and HOME transaction environments.

## Managed AgentFlow payload refresh

- Refreshed managed AgentFlow governance assets, including `lib/world/world-builder.mjs`, core seat lifecycle modules (`lib/core/seat-claim.mjs`, `lib/core/seat-lease.mjs`, `lib/core/seat-prime.mjs`), `adapters/openrig/agentflow-world`, and transition envelope schemas.

## OpenObserve dashboards and collector support

- Added OpenObserve dashboard suite and collector pipeline under `contrib/dashboards/openobserve/`.
- Five dedicated dashboards covering Fleet Portfolio, Workspace / Project, Agent Workflow, Session / Turn, and Telemetry Operations (`dashboards/01-fleet-portfolio.json` through `05-telemetry-operations.json`).
- Automated dashboard build and provisioning toolchains (`build.mjs`, `provision.mjs`) with accompanying test suites.
- OpenTelemetry Collector configuration for OpenObserve export (`collector/otel-collector-openobserve.yaml`).

## Upgrade

```text
agent-otel-bridge local install
agent-otel-bridge hooks install --all-homes
agent-otel-bridge doctor
```

## Validation limits

Desktop and IDE live sessions are not certified. Linux `agent-hook` executes strictly in passive mode (`{}`) and does not inject environment variables or emit harness approval output. IPC admission loss under sustained stress remains open in [RES-004](../resilience-backlog.md).
