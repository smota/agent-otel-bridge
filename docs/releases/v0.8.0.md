# Release v0.8.0 — Ecosystem alignment

The default export is unchanged. Operators who already collect v0.7.0 spans can upgrade the binaries and keep the same dashboards. Standard OTLP environment variables, optional experimental GenAI fields, and paired Pre/Post spans are available when you turn them on.

## Export

The daemon reads the OTLP/HTTP environment contract.

- A signal-specific endpoint is used verbatim. A base endpoint still receives `/v1/traces` and `/v1/metrics`.
- Headers, gzip or no compression, timeout, and an extra root certificate follow that contract. An unset timeout stays 5000 ms.
- Only `http/protobuf` is sent. `grpc` or any other protocol selection disables that signal and opens no connection.
- `OTEL_SDK_DISABLED=true` accepts events and exports nothing. The daemon still starts.
- Retry applies to 429, 502, 503, and 504, including `Retry-After`, and partial success is honored.

The exporter stays the handwritten HTTP client. This release does not add a gRPC client or an `opentelemetry-otlp` dependency on the daemon.

## Resource

An empty deployment environment is omitted. The daemon does not invent `homelab`, and it does not copy `deployment.environment` onto `deployment.environment.name` or the reverse.

`service.instance.id` is 32 lowercase hex characters, generated once per daemon process, unless `OTEL_RESOURCE_ATTRIBUTES` sets that key. `telemetry.sdk.name` is `agent-otel-bridge`, the language is `rust`, and the SDK and distro versions follow the service version. `os.type` is `darwin` on macOS. `OTEL_SERVICE_NAME` wins over `service.name`. `OTEL_SERVICE_VERSION` sets the initial `service.version`; a `service.version` entry in `OTEL_RESOURCE_ATTRIBUTES` overrides that one attribute.

## Spans

`OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental` is a comma-separated, case-sensitive token. Other tokens are ignored. When it is set, trace spans use schema `https://opentelemetry.io/schemas/1.41.0` and the experimental field set: no `gen_ai.system`, `gen_ai.provider.name` only when a model is present and the inferred provider is not `unknown`, finish reasons as a one-element string array, `error.type` from the error category or `_OTHER`, success status left unset, lineage on `agent.lineage.*`, and VCS on `vcs.ref.head.name` and `vcs.ref.head.revision`. The default path is unchanged.

The daemon pairs `PreToolUse` with `PostToolUse` into one `execute_tool` span, and `PreInvocation` with `PostInvocation` or `Stop` into one `invoke_agent` span. Duration is the interval between those hook deliveries as the daemon observes them. It is not a harness CPU timer. `agent.span.paired` is true for a pair. Unpaired spans keep equal start and end. The open map holds 1024 spans for 60 seconds and is not written to disk. A release microbench of 10,000 Pre+Post observations recorded p99 1863 ns (`cargo test -p agent-otel-daemon --release -- --ignored pairing`).

On `PreToolUse`, the hook echoes an inbound `TRACEPARENT` whose bytes are only hex or `-`, and an inbound `TRACESTATE` of 1 to 512 printable ASCII bytes excluding quotes, backslashes, and controls. Either value can be absent. The hook does not mint `00-{trace}-{span}-01`.

## Metrics and privacy

With the same opt-in token, bridge counters drop the `.total` suffix. The default names keep it. Both forms are not emitted together. A helper names the fleet token-rate gauge `agent.fleet.token_rate` with unit `{token}/min` under that opt-in, and `agent.fleet.token_rate_minute` otherwise. Quota export does not emit the gauge.

`user.email` comes from the hook payload or `$USER_EMAIL`. Git config and `$GIT_AUTHOR_EMAIL` are read only when `AGENT_OTEL_ENRICH_EMAIL` is `true` or `1`. `AGENT_OTEL_WORKSPACE_PATH` is `absolute` (the default), `relative`, or `hash`. Under the experimental field set, an error status message is truncated to 160 bytes on a character boundary.

## Collector

`contrib/collector/` contains `local.yaml`, `team.yaml`, and `span-metrics.yaml`. The span-metrics example counts calls in the `agent.span` namespace and leaves the duration histogram off. `contrib/dashboards/grafana/agent-otel-bridge.json` is a dashboard without alerts or a duration percentile. `semconv/registry.yaml` is a project snapshot; `weaver registry check -r semconv` passed locally with Weaver 0.28.0.

## Upgrade

```text
agent-otel-bridge local install
agent-otel-bridge local enable --app <client>
agent-otel-bridge doctor
```

No new installer path. Leave `OTEL_SEMCONV_STABILITY_OPT_IN` unset to keep the v0.7.0 wire shape.

## Validation limits

Desktop and IDE live sessions are not certified. The hook does not mint a child traceparent. The fleet token-rate gauge is not on the wire. There is no gRPC exporter. Paired duration is a hook-to-hook observation, and the span-metrics duration histogram stays disabled. `otelcol-contrib validate` was not run in the release environment. IPC admission loss under sustained stress remains open in [RES-004](../resilience-backlog.md).
