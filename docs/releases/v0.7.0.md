# Release v0.7.0 — Per-application enablement

`local install` publishes the bridge binaries and leaves harness configuration alone. Telemetry is enabled per application.

## Enablement

```text
agent-otel-bridge local enable --app claude
agent-otel-bridge local enable --app codex
agent-otel-bridge local enable --app antigravity
agent-otel-bridge local enable --app grok
agent-otel-bridge local enable --app pi
```

`local disable --app <client>` reverses that application's registration.

- Claude stages a marketplace and runs `claude plugin marketplace add` and `claude plugin install agent-otel-bridge@agent-otel-bridge --scope user`.
- Codex stages `.agents/plugins/marketplace.json` and a plugin whose hooks use the portable Codex command. It then runs `codex plugin marketplace add` and `codex plugin add agent-otel-bridge@agent-otel-bridge`. This path does not write `~/.codex/hooks.json` or Codex trust files. Trust review remains with Codex.
- Antigravity CLI stages a plugin and runs `agy plugin install`. The hook object is the same one the Antigravity installer stores under `agent-otel-bridge`.
- Grok writes only `~/.grok/hooks/agent-otel.json`.
- Pi writes only the managed extension `~/.pi/agent/extensions/agent-otel-bridge.ts`. It does not create `hooks.json`. Uninstall still removes that extension and may clean a legacy `hooks.json`. An unowned extension is refused.

If the vendor CLI cannot be spawned, enable fails and does not write under that application's home directory. Staging under the bridge runtime `plugins-stage` directory is allowed. If the daemon health ping fails, enable starts the existing daemon.

`install-hooks` and `hooks install` without `--legacy-config` tell the operator to run `agent-otel-bridge local enable --app <client>` and exit 2. They write nothing. `--legacy-config` keeps today's JSON merger, including third-party hook preservation.

`local install` and `local rollback` default `--update-hooks` to false.

## Doctor

Doctor prints one row each for `antigravity-cli`, `antigravity-ide`, `claude`, `codex`, `grok`, and `pi`, in addition to the existing adapter lines. A missing home directory is `not detected`, not an error. When Codex `hooks.json` contains a bridge command, the row says that trust review remains with Codex.

## Upgrade

Install the binaries, then enable each application you want:

```text
agent-otel-bridge local install
agent-otel-bridge local enable --app <client>
agent-otel-bridge doctor
```
